# 🚀 빠른 시작 가이드

## 1️⃣ 환경 설정 (1분)

### .env 파일 생성
```bash
cd backend
cp .env.example .env
```

### .env 파일 수정
```env
INFLUXDB_URL=http://localhost:8086
INFLUXDB_TOKEN=여기에_실제_토큰_입력
INFLUXDB_ORG=robot-fleet
INFLUXDB_BUCKET=robot-monitoring
```

> 💡 **토큰 얻는 방법:**
> 1. `http://localhost:8086` 접속
> 2. Load Data → API Tokens → Generate API Token
> 3. 생성된 토큰 복사 후 `.env` 파일에 붙여넣기

---

## 2️⃣ 패키지 설치 (30초)

```bash
pip install -r requirements.txt
```

---

## 3️⃣ 더미 데이터 생성 (2분)

```bash
python quick_generate.py
```

**생성 내용:**
- ✅ 과거 24시간 데이터 (3분 간격)
- ✅ 실시간 10분 데이터 (3초 간격)
- ✅ 9대 로봇 (Robot-arm 3 + UGV 3 + Drone 3)

---

## 4️⃣ API 서버 실행 (10초)

```bash
python main_with_influx.py
```

**접속 주소:**
- 🌐 API: http://localhost:8000
- 📚 문서: http://localhost:8000/docs

## ✅ 완료!

이제 프론트엔드에서 다음 API를 호출할 수 있습니다:

```javascript
// 모든 로봇 데이터
fetch('http://localhost:8000/api/robots')

// 특정 로봇 데이터
fetch('http://localhost:8000/api/robots/RA001')

// 시계열 데이터 (최근 24시간)
fetch('http://localhost:8000/api/robots/RA001/timeseries?hours=24')
```

## 🔄 실시간 데이터 계속 생성하기

더미 데이터 생성기를 백그라운드에서 실행:

```bash
python generate_dummy_data.py
# 메뉴에서 '2' 선택 (실시간 데이터 생성)
# 원하는 시간(분) 입력: 999999 (거의 무한)
```

또는 별도 터미널에서:

```bash
# 1시간마다 자동으로 재시작
while true; do
    python -c "from generate_dummy_data import RobotDataGenerator; g = RobotDataGenerator(); g.connect(); g.generate_realtime_data(60, 3)"
    sleep 1
done
```

## 🐛 문제 발생 시

### "InfluxDB 연결 실패"
```bash
# InfluxDB 실행 확인
docker ps | grep influxdb

# 없으면 시작
docker-compose up -d influxdb
```

### "토큰 인증 실패"
1. InfluxDB UI에서 새 토큰 생성
2. `.env` 파일 업데이트
3. API 서버 재시작

### "데이터가 없음"
```bash
# 더미 데이터 다시 생성
python quick_generate.py
```
